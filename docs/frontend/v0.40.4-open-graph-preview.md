# v0.40.4 — Open Graph preview card

The frontend now ships `public/og.png` (1200 × 630) and declares it through
`og:image` / `twitter:image` in `index.html`, with `summary_large_image` as the
Twitter card type. The card carries only the wordmark, the tagline
"Evidence before inference." and the four pipeline stages; it shows no
fixture dollar amounts or accuracy numbers, so it never needs to change when
demo data changes.

Deploy from `frontend/` as usual. Social platforms cache the previous scrape:
after deploying, submit the URL to LinkedIn Post Inspector (or re-add the
link) to pick up the new image.

Version record: `docs/versions/v0.40.x/v0.40.4-frontend-open-graph-preview.md`.
