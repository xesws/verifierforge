# v0.40.4 — Frontend Open Graph preview

**Status:** complete
**Date:** 2026-09-08
**Owner/worktree:** primary agent on `main`
**Release type:** frontend asset / metadata patch

## Problem and scope

Sharing `https://verifierforge-web.vercel.app` on LinkedIn or X produced a
card with no image because the page declared no `og:image`. Add a static
1200 × 630 preview card and the Open Graph / Twitter Card meta tags that point
at it, so link unfurls show the product name, tagline and pipeline.

## Explicit non-goals

- No product UI, routing, favicon, wordmark, color or copy change inside the app.
- No dynamic per-route previews; one static card for the whole site.
- No change to the backend, contracts, mock, or Python packages.

## Affected areas and validation

- `frontend/public/og.png`: 1200 × 630 PNG rendered from the canonical
  `assets/brand/verifierforge-wordmark.svg` plus the site tagline and the
  Discover → Forge → Prove → Ship pipeline. Fixture numbers are deliberately
  absent from the card.
- `frontend/index.html`: `og:*` and `twitter:*` meta tags with absolute URLs.
- `docs/frontend/v0.40.4-open-graph-preview.md`: area record.

Validate with `npm run build` in `frontend/` (the tags must survive into
`dist/index.html` and `dist/og.png` must exist), then after deployment run the
production URL through LinkedIn Post Inspector to force a re-scrape.

## Contract impact

None. No shared contract, API, mock or fixture is touched.
